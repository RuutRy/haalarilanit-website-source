## Your LAN seat

- Your LAN seat is <Mark>90 cm</Mark> wide.
- A chair is provided (you may bring your own too).
- One power outlet is available for your setup (please bring your own extension cord).
- The network port may be several meters away (a <Mark>10 m</Mark> Ethernet cable will definitely be sufficient).

## Game servers

The event LAN has ready-made game servers for popular games such as CS2, Team Fortress 2, Minecraft and Valheim.

You can also ask the IT-team to set up your own game server for the game of your choice for the duration of the event, as long as server capacity allows.

The event also has a Mumble voice chat. Thanks to the LAN, the voice chat latency is practically <Mark>0 ms</Mark>, so Mumble is the recommended way to chat with your fellow LAN attendees. Download Mumble from [mumble.info](https://www.mumble.info/).

## Game downloads

Download your games and their updates before the event, so the event network is not overloaded unnecessarily. The event network runs a Lancache, which speeds up game downloads and prevents the network from getting overloaded: as long as someone has already downloaded that game or update, everyone else gets it straight from the cache. Downloading your games in advance is still recommended.

For Lancache to work, use the event's own DNS servers (no need to change anything unless you've specifically changed them). However, most VPN apps, Cloudflare WARP and other apps that change your DNS server can bypass Lancache, so game downloads will not use the cache.
